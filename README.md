# Gradio_Dice_Roller 🎲

A dice roller made with Python and Gradio. Click the "Roll the Dice!" button and watch the dice spin before it lands on a random number. There is also a "Reset" button to start over. It is a fun project for Python beginners.

![Dice roller demo](demo.gif)

## Features

- Animated dice that slows down before stopping
- Large dice faces
- Shows the number you rolled
- Reset button
- Custom Gradio theme

## How to run

1. Install the requirement:
```
   pip install -r requirements.txt
```
2. Run the app:
```
   python app.py
```
3. Open the local link shown in the terminal (usually http://127.0.0.1:7860).
